# overworked
Christmas version of Overcooked. 

Build as many gifts as you can within the time limit to score points! Work with your AI teammate by issuing commands! Build gifts by utilizing 3D printers and laser cutters with PLA and leather. Follow the recipes. Good Luck!

Keybinds
WASD - Move
SPACE - Pick Up
J - Run Machine
L - Pick Up Placed Leather
1,2,3,4 - Select Recipe -> K - Submit Request to AI
P,O,I - Change AI Mode

AI Features
Three operational modes: PLA-only, Leather-only, and Manual command
NavMesh-based pathfinding with obstacle avoidance
State machine architecture for task execution
Multi-step recipe workflows (gather → process → deliver)
Automatic stuck detection and error recovery
Dynamic recipe selection and prioritization
Real-time mode switching via keyboard controls (P/O/I keys)

Unity Editor Version is 2022.3.10f1
